Comunicaciones

DNP3 - Distributed Network Protocol

Descripción General

DNP3 es un protocolo de comunicación estándar desarrollado para sistemas SCADA en servicios públicos. Es ampliamente utilizado en la industria eléctrica, agua y gas para la comunicación entre equipos de telecontrol y unidades remotas.

Características Principales

  • Protocolo robusto diseñado para comunicaciones confiables
  • Soporte para múltiples tipos de datos (analógicos, digitales, contadores)
  • Funciones de reporting y evento disparado
  • Autenticación y encriptación de seguridad (DNP3 Secure Authentication)
  • Compatible con múltiples medios de transmisión (serie, Ethernet, IP)

Aplicaciones

  • Sistemas SCADA en subestaciones eléctricas
  • Control remoto en sistemas de distribución
  • Comunicación con RTU (Remote Terminal Units)
  • Integración de sistemas de control distribuidos

IEC 60870-5-104 (IEC 104)

Descripción General

IEC 60870-5-104 es un estándar internacional para comunicación cliente-servidor en sistemas de automatización y control de energía. Utiliza una arquitectura basada en TCP/IP que permite la comunicación por redes estándar.

Características Principales

  • Basado en estándar IEC 60870-5-101 pero sobre TCP/IP
  • Comunicación orientada a conexión
  • Multiplexación de canales ASDU (Application Service Data Units)
  • Supervisión de conexión con mecanismos de keepalive
  • Soporte para tiempo de sincronización
  • Integración en sistemas Ethernet y redes modernas

Aplicaciones

  • Comunicación entre SCADA y subestaciones
  • Sistemas de control remoto en redes eléctricas
  • Monitoreo y control de plantas de distribución
  • Sistemas de protección y automatización
  • Integración con infraestructura IT moderna
