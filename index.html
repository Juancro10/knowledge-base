Definiciones - Glosario de Términos Técnicos

Telemetría

Definición: Tecnología para recopilar datos de dispositivos o sistemas remotos y transmitirlos a un sistema de control central. Los datos se recopilan típicamente de sensores o equipos de monitoreo, como temperatura, presión o ubicación.

Ejemplo: Una sonda espacial que transmite datos de velocidad, temperatura y posición a la Tierra es un ejemplo de telemetría.

Teleseñalización / Señalización Remota

Definición: Transmisión de señales de estado o alarma desde equipos remotos, generalmente como datos discretos (ej. ENCENDIDO/APAGADO, Normal/Fallo).

Ejemplo: Un centro de control de planta recibiendo una señal de "interruptor cerrado" desde una subestación es una instancia de señalización remota.

Telecontrol / Control Remoto

Definición: Operación u control remoto de dispositivos, como encender/apagar equipos, configurar parámetros o iniciar procesos.

Ejemplo: Iniciar remotamente una máquina de fábrica o encender un aire acondicionado es una forma de telecontrol.

DSP - Procesador Digital de Señales

Definición: Microprocesador especializado diseñado para procesamiento numérico de alta velocidad, ampliamente utilizado en telecomunicaciones, audio, procesamiento de imágenes digitales, radar, sonar y electrónica de consumidor.

RTU - Unidad Terminal Remota

Definición: Dispositivo electrónico basado en microprocesador que actúa como interfaz con dispositivos de campo y transmite datos de telemetría al sistema SCADA, mientras que también recibe comandos de control.

IED - Dispositivo Electrónico Inteligente

Definición: Dispositivo electrónico avanzado capaz de procesamiento de datos y comunicación, utilizado en sistemas de potencia y control industrial para monitoreo, control, protección y comunicación. Va más allá de sensores o relés simples al incorporar microprocesadores e interfaces de comunicación.

COT - Causa de Transmisión

Definición: Campo crítico dentro de la ASDU (Unidad de Datos del Servicio de Aplicación) en IEC 60870-5, que indica la razón de la transmisión de datos (ej. cíclica, espontánea, prueba).

IOA - Dirección del Objeto de Información

Definición: Identifica la dirección interna de un punto específico dentro de un dispositivo. Cada RTU o IED típicamente tiene una lista de puntos, y la IOA se utiliza para hacer referencia a esos puntos.

Trama

Definición: Unidad básica de encapsulación de datos en protocolos de comunicación industrial, consistente en un encabezado (Inicio de Trama, dirección, código de función), carga útil y CRC (verificación de error).

SCADA - Supervisión, Control y Adquisición de Datos

Definición: Arquitectura de sistema utilizada para monitoreo y control remoto de grandes sistemas industriales. Los sistemas SCADA permiten a operadores centralizados supervisar dispositivos de campo, enviar comandos de control y visualizar/analizar datos en tiempo real.

Barra

Definición: Conductor de cobre o aluminio que recibe energía en una subestación eléctrica. Es el punto común donde se conectan múltiples circuitos. Existen barras principales y barras de transferencia en un sistema eléctrico.

Paño / Bahía

Definición: Unidad modular de equipamiento en una subestación que contiene los elementos de control y protección para un circuito o línea específica. Incluye interruptores, desconectadores, medidores y relés de protección organizados en una estructura única.

Protección

Definición: Sistema de dispositivos y relés que detectan condiciones anormales (cortocircuitos, sobrecargas, fallas) en el sistema eléctrico y ejecutan acciones correctivas automáticas como desconectar líneas para proteger el equipo y mantener la estabilidad del sistema.

Medidor

Definición: Dispositivo que cuantifica el consumo o flujo de energía eléctrica, agua, gas u otro recurso. En sistemas eléctricos, registra la energía activa, reactiva y otros parámetros para facturación y análisis del consumo.

Controlador

Definición: Dispositivo inteligente programable que toma decisiones basadas en señales de entrada y ejecuta acciones sobre dispositivos de salida. En sistemas de potencia, mantiene parámetros dentro de rangos especificados (ej. reguladores de voltaje, gobernadores de velocidad).

89 = Desconectador

Definición: Código ANSI-IEEE que identifica un desconectador (switch de desconexión). Dispositivo de separación manual o motorizado que desconecta circuitos sin carga. Se usa para aislar equipos durante mantenimiento o para cambiar la configuración de la red.

52 = Interruptor

Definición: Código ANSI-IEEE que identifica un interruptor de potencia (circuit breaker). Dispositivo automático que interrumpe el flujo de corriente cuando detecta una falla, protegiendo el sistema. Puede operar bajo carga y condiciones de cortocircuito.

89 con T = Desconectador de Tierra

Definición: Código ANSI-IEEE que identifica un desconectador de tierra. Dispositivo que conecta circuitos a tierra para garantizar seguridad durante trabajos de mantenimiento. Disipa a tierra cualquier carga residual o voltaje peligroso.

CFE

Definición: Comisión Federal de Electricidad (México). Empresa productora, transportista y distribuidora de energía eléctrica en México. Es responsable de la generación, transmisión y distribución de electricidad a nivel nacional.

ICCP

Definición: Inter-Control Center Communications Protocol. Protocolo estándar de comunicación entre centros de control SCADA para intercambiar información de telemetría, eventos y comandos. Permite integración de sistemas de múltiples operadores.

IMM

Definición: Information Model Management. Modelo de gestión de información en sistemas Spectrum Power 5 que define la estructura, tipos de datos y relaciones de toda la información del sistema SCADA, facilitando interoperabilidad e integración.

CEN (Chile)

Definición: Centro de Energía Nacional de Chile. Entidad que gestiona y coordina el sistema eléctrico chileno, garantizando confiabilidad, seguridad y eficiencia en la operación integrada de generación, transmisión y distribución.

Enlace

Definición: Conexión o trayecto de comunicación entre dos puntos de red. Puede ser un cable de comunicación serie, línea Ethernet o cualquier medio físico que permite transmisión de datos entre dispositivos o sistemas.

VPN - Red Privada Virtual

Definición: Tecnología de seguridad que establece una conexión cifrada sobre una red pública (como Internet), permitiendo comunicación segura entre sitios remotos. Protege datos mediante encriptación y autenticación.

Escritorio Remoto

Definición: Tecnología que permite acceder y controlar una computadora desde otra ubicación remota como si estuviera físicamente presente. Transmite la interfaz gráfica del escritorio y acepta comandos del usuario remoto.

DNP3 - Distributed Network Protocol

Introducción

DNP3 (Distributed Network Protocol versión 3.0) fue desarrollado para alcanzar interoperabilidad abierta y estándar entre elementos de subestaciones y estaciones principales de compañías eléctricas. Desarrollado por Harris en noviembre de 1993 y entregado al Grupo de Usuarios de DNP3 (conformado por más de 300 usuarios y fabricantes), se ha expandido ampliamente a industrias como agua, tratamiento de aguas residuales, petróleo y gas.

Ventajas de DNP3

  • Flexibilidad y funcionalidades superiores a protocolos convencionales
  • Opciones de salidas y transferencia de archivos
  • Direccionamiento sobre 65,000 dispositivos en un enlace simple
  • Sincronización y eventos con estampa de tiempos
  • Confirmación de enlace de datos y alto nivel de integridad

Características Técnicas Principales

  • Los mensajes se separan en varias tramas para proporcionar control óptimo de error y secuencias rápidas
  • Topología igual-igual, maestro-esclavo y múltiples maestros
  • Solicitudes y respuestas con múltiples tipos de datos en un solo mensaje
  • Comunicación de excepciones/eventos sin encuestas (Respuestas no solicitadas)
  • Mensajes en Broadcast para todas las estaciones esclavas
  • Transferencia segura de configuración y archivos
  • Confirmaciones en Capa de Enlace y Capa de Aplicación
  • Asignación de prioridades a grupos de datos (clases)

Modelo de Capas

DNP3 utiliza un modelo simplificado que se asemeja al protocolo OSI de 7 capas, pero omite algunas funciones de nivel superior. Sigue el modelo EPA (definido por IEC) con 3 capas principales:

  • Capa Física: Base del modelo
  • Capas intermedias: Control y transferencia de datos
  • Capa de Aplicación: Funciones de nivel superior

Estructura de Mensajes

  • Fragmentos (Capa de Aplicación): Tamaño máximo de 1024 bytes
  • Segmentos (Capa de Transporte): Permiten transmisión de bloques largos
  • Tramas (Capa de Enlace): Tamaño máximo de 292 bytes

Nivel de Enlace (Link Layer)

Una trama DNP3 consta de tres bloques diferenciados:

  • Cabecera DNP3 (10 bytes): Incluye bytes de inicio (0x05, 0x64), tamaño de trama, código de control, direcciones de destino y origen (2 bytes cada una en big-endian), y 2 bytes de CRC
  • Datos: Cada 16 bytes de datos más al final de la trama hay 2 bytes de CRC
  • Verificación de Redundancia Cíclica (CRC): Para detección de errores, basado en especificaciones IEC 60870-5

El nivel de enlace es balanceado, donde tanto la estación controladora como la controlada tienen responsabilidad en envío de datos y gestión del enlace.

Capa de Transporte (Pseudo Transporte)

Permite la transmisión de datos en bloques largos. Utiliza bits FIR (First Frame) y FIN (Final Frame) para controlar la secuencia de tramas (0-63). Reglas importantes:

  • Si se recibe una trama con FIR, cualquier secuencia incompleta es descartada
  • Sin FIR y sin secuencia en progreso, la trama es ignorada
  • El número de secuencia debe incrementarse después de la trama inicial
  • El rango de secuencia es 0 a 63

Capa de Aplicación

La capa de aplicación responde a mensajes completos recibidos. Cuando los datos son demasiado grandes, se construyen múltiples mensajes y se transmiten secuencialmente. Proporciona:

  • Control de Aplicación: Las confirmaciones indican recepción y análisis sin error
  • Función de Aplicación: Código que indica el propósito/operación solicitada del mensaje
  • Indicaciones Internas: Conocer el estado del equipo remoto (2 bytes en dispositivos esclavos)
  • Grupos y Variaciones: Identifican el tipo de dato del objeto
  • Estructura de la Información: Organización de datos (rangos secuenciales o listados no consecutivos)

Aplicaciones Prácticas

  • Sistemas SCADA en subestaciones eléctricas
  • Control remoto en sistemas de distribución
  • Comunicación con RTU (Remote Terminal Units)
  • Integración de sistemas de control distribuidos
  • Sistemas de monitoreo en plantas de tratamiento de agua
  • Comunicación en sistemas de petróleo y gas

IEC 60870-5-104 (IEC 104)

Descripción General

IEC 60870-5-104 es un estándar internacional para comunicación cliente-servidor en sistemas de automatización y control de energía. Utiliza una arquitectura basada en TCP/IP que permite la comunicación por redes estándar.

Características Principales

  • Basado en estándar IEC 60870-5-101 pero sobre TCP/IP
  • Comunicación orientada a conexión
  • Multiplexación de canales ASDU (Application Service Data Units)
  • Supervisión de conexión con mecanismos de keepalive
  • Soporte para tiempo de sincronización
  • Integración en sistemas Ethernet y redes modernas

Aplicaciones

  • Comunicación entre SCADA y subestaciones
  • Sistemas de control remoto en redes eléctricas
  • Monitoreo y control de plantas de distribución
  • Sistemas de protección y automatización
  • Integración con infraestructura IT moderna
