# Base de Conocimiento - Spectrum Power 5

Una plataforma web moderna para centralizar y organizar toda la documentación técnica del equipo.

## 📋 Características

- 🔍 Búsqueda rápida de documentos y procedimientos
- 📚 Organización por módulos temáticos
- 🎨 Interfaz limpia y profesional
- 📱 Diseño responsive para cualquier dispositivo
- ⚡ Carga instantánea

## 📁 Módulos

- **SCADA** - Adquisición de datos, telecontrol y visualización en tiempo real
- **EMS** - Gestión de energía: estimación de estado, flujos de carga y contingencias
- **DMS / OMS** - Gestión de distribución y restauración de interrupciones
- **Alarmas y eventos** - Configuración, filtrado y gestión de alarmas
- **Modelo de datos e HIS** - Gestión de información histórica y almacenamiento
- **Administración** - Configuración del sistema y gestión de usuarios
- **Comunicaciones** - Protocolos de comunicación y transferencia de datos
- **Formación** - Recursos educativos y capacitación de usuarios

## 🚀 Instalación

1. Clona este repositorio:
```bash
git clone <tu-repositorio>
cd knowledge-base-repo
```

2. Abre el archivo `index.html` en tu navegador o sirve con un servidor local:
```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000` en tu navegador.

## 📝 Personalización

Edita el archivo `index.html` para cambiar:
- Nombre del proyecto (en el header y hero section)
- Descripción de módulos
- Cantidad de documentos y categorías
- Placeholder del buscador
- Colores y estilos (en la sección `<style>`)

## 🎨 Colores principales

- Fondo oscuro: `#0a1620`
- Turquesa: `#17a2b8`
- Naranja: `#f39c12`
- Gris claro: `#f0f0f0`
